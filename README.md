# Desafio Técnico — Desenvolvedor de Sistemas Jr.

Seja bem-vindo(a) ao repositório do meu desafio técnico!

Este projeto foi desenvolvido como parte do processo seletivo para a vaga de **Desenvolvedor de Sistemas Júnior**, com o objetivo de demonstrar minhas habilidades em desenvolvimento front-end, lógica de programação e construção de interfaces web.

## 🚀 Projeto publicado

Acesse a aplicação funcionando:

🔗 [Visualizar projeto na Netlify](https://joyful-paprenjak-8cfbf2.netlify.app/)

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização, identidade visual e apresentação da interface.
- **JavaScript** — implementação da lógica e das funcionalidades da aplicação.

## 🎨 Decisões de desenvolvimento

Durante a implementação, busquei atender aos requisitos propostos, priorizando a clareza do código, a simplicidade da estrutura e a experiência do usuário.

A escolha da cor azul teve como objetivo transmitir profissionalismo, confiança e consistência visual. Para facilitar a implementação e a publicação, concentrei a lógica da aplicação em um único arquivo.
